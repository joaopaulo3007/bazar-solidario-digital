# Bazar Solidário Digital

Projeto acadêmico de extensão do curso de Ciência da Computação da UniAnchieta.

**Aluno:** João Paulo de Moraes Felisardo  
**Instituição parceira:** Paróquia São Benedito — Várzea Paulista, São Paulo.

## Sobre o projeto

Protótipo de site para divulgação de peças de vestuário de um bazar beneficente. Oferece catálogo digital de roupas, categorias, pesquisa, filtros e sacola de interesse, com interface adaptada para dispositivos móveis.

## Tecnologias

HTML, CSS e JavaScript.

## Aviso

O catálogo tem finalidade demonstrativa. Produtos, disponibilidade e preços são ilustrativos e não representam ofertas reais da Paróquia. O desenvolvimento do protótipo não constitui, por si só, comprovação de atividades presenciais ou da carga horária total do projeto extensionista.

## Acesso ao protótipo

Para executar localmente, abra `index.html` no navegador.

Após habilitar o GitHub Pages em **Settings > Pages** (Deploy from a branch, branch `main`, pasta `/ (root)`), o endereço previsto será:

https://joaopaulo3007.github.io/bazar-solidario-digital/
